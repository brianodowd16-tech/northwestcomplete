# Northwest Complete: launch campaign kit

Everything here is for **posting**, not for the website (the deploy workflow skips this folder).

## Folders
- `profile/`: Instagram profile picture, LinkedIn banners (personal and company page)
- `images/`: every post image, 1080 x 1350 (4:5). Carousels are numbered `-01`, `-02`, ...
- `linkedin-carousels/`: PDFs to upload as LinkedIn "document" posts (swipeable)
- `content-calendar.csv`: dates, captions, links and image names (works with Buffer, Metricool or Google Sheets)
